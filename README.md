# M4 Launcher

Android 런처 시험 배포 공간입니다. 앱 소스와 서명 키는 포함하지 않습니다.

## 다운로드

[1.4.0-rc16 APK 받기](https://github.com/DANDAN-TT/m4-launcher/releases/tag/v1.4.0-rc16)

설정 7개 분류와 홈·앱 메뉴를 점검해 삭제·초기화·기본 홈 덮어쓰기·재시작 확인을 추가했습니다. 음악 권한과 기본 런처 지정 상태, 출력 방식 적용 대기를 표시합니다. 업데이트 설치 권한을 켜고 돌아오면 파일을 다시 검증하고 설치를 이어갑니다. 이전 내비 광고 닫기 설정 이동·등록 상태·해제 확인과 성능 개선도 포함합니다.

## 설치와 업데이트

기존 M4 Launcher 배포본은 같은 패키지 `com.totb.m4launcher`와 서명을 유지하므로 APK를 설치해 업데이트할 수 있습니다. 저장한 설정과 앱 선택을 유지합니다.

이전 `com.totb.drivedeck` 앱을 사용한다면 별도 앱으로 설치됩니다. **기존 앱에서 설정 백업 → M4 Launcher 설치 → 설정 복원 → 기본 런처·연결 권한 설정** 순서로 진행하세요.

APK와 업데이트 정보는 GitHub 로그인 없이 받을 수 있습니다. 시험 배포는 preview 채널을 사용합니다. 앱의 **설정 → 관리·업데이트 → 시험 버전 받기**를 켜고 업데이트를 확인하세요.
