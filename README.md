# M4 Launcher

Android 런처 시험 배포 공간입니다. 앱 소스와 서명 키는 포함하지 않습니다.

## 다운로드

[1.4.0-rc34 APK 받기](https://github.com/DANDAN-TT/m4-launcher/releases/tag/v1.4.0-rc34)

설정을 화면·분할·홈 화면·앱·내비·조작·테마·기기·관리로 정리하고, 큰 분류 → 세부 메뉴 → 설정 내용으로 구성했습니다. 버튼 바는 세로 가운데에 정렬하며, 즐겨찾기·최근 앱·앱은 버튼 위치에 맞춘 버블로 열립니다. 하단 상태줄에서 날씨·날짜·시간·CPU 온도·사용률·연결 상태를 확인합니다.

기본 홈 앱이 아니면 실행 시 설정을 안내합니다. 루트 연결에서는 내비 광고 닫기를 켤 때 M4 Launcher 접근성을 자동으로 준비하며 다른 앱의 접근성을 보존합니다. 개발자 옵션은 설정 열기 버튼 하나로 정리했습니다.

## 설치와 업데이트

기존 M4 Launcher 배포본은 같은 패키지 `com.totb.m4launcher`와 서명을 유지하므로 APK를 설치해 업데이트할 수 있습니다. 저장한 설정과 앱 선택을 유지합니다.

이전 `com.totb.drivedeck` 앱을 사용한다면 별도 앱으로 설치됩니다. **기존 앱에서 설정 백업 → M4 Launcher 설치 → 설정 복원 → 기본 런처·연결 권한 설정** 순서로 진행하세요.

APK와 업데이트 정보는 GitHub 로그인 없이 받을 수 있습니다. 앱의 **설정 → 관리 → 업데이트 설정 → 시험 버전 받기**를 켠 뒤 **버전 업데이트 → 새 버전 확인**을 누르세요.

## 엠스틱 관리

**설정 → 기기 → 기기 연결 → 엠스틱 관리(루트)**에서 Mgears 업데이터 비활성화, 부팅 안내창 숨김, 흰색 시스템 버튼 숨김과 CPU 최대 클럭 약 90%·80% 제한을 설정합니다. 변경 확인과 적용 상태 표시, 이전 설정 복구를 제공합니다.

루트 권한이 필요하며 부팅 안내·CPU 유지에는 Magisk가 필요합니다. 검사한 Mstick4 펌웨어 1.9.4·Mstick 앱 2.39.9에서 지원합니다. CPU는 최대 클럭을 제한하며 기기의 과열 보호를 유지합니다. 시스템 버튼 숨김은 제조사 설정을 사용합니다. 앱 삭제만으로 기기 설정이 복구되지 않으므로 해제하거나 전체 복구를 먼저 사용하세요.

## 날씨와 접근성

현재 위치 날씨는 대략적인 위치 권한으로 조회하며 이동 기록을 저장하지 않습니다. 위치가 잡히지 않으면 지역을 직접 선택할 수 있습니다. 기기 센서 온도와 예보 기온은 구분해 표시합니다.

내비 광고 닫기는 접근성으로 지원 내비의 닫기 버튼을 누릅니다. 광고 다운로드 차단 기능은 아닙니다. 루트 자동 준비가 실패하면 Android 접근성 설정으로 안내합니다.

## 검증

release/debug 빌드, JVM 단위 테스트 각각 790개(실패·오류·건너뜀 0개), 린트 오류 0개·경고 143개, 한·영 문자열 1071쌍, Android 테스트 APK 컴파일과 기존 서명 검증을 통과했습니다.

실제 Android 13 엠스틱4에 USB로 설치하여 설정 9개 분류, 버튼 간격과 버블 위치, 동일한 온도 표시, 기본 홈 앱 안내와 개발자 설정 열기를 확인했습니다. 루트 접근성 자동 연결과 OEM 접근성 보존도 확인했습니다. 무선 디버깅은 꺼진 상태를 유지했습니다.

현재 위치 날씨는 위치 권한 흐름까지 확인했으며 실내 위치 수신이 없어 자동 예보 성공은 미검증입니다. 수동 서울 예보 응답은 확인했습니다. 사용자 기기의 전체 자동 계측 묶음, 실제 차량 부팅 안내창 생략 장면, 상용 내비 광고·DRM 재생·발열 감소량은 미검증입니다.
