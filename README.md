없어# M4 Launcher — 개인 비공개 배포

이 저장소는 DANDAN-TT 소유의 비공개 APK 배포 공간입니다.

## 현재 상태

- 준비 중인 개발 버전: 1.4.0-rc12-dev (versionCode 90).
- 추가 기능: 앱 자리 교환, 시작 지연·인터넷 대기·순차 실행, 조합별 DPI, 최근 앱 버튼, 넓은 하단 바 조합 바로가기.
- 로컬 검사: 단위 테스트 749개 통과, 린트 오류 0개·경고 141개, 디버그 빌드와 기기 테스트 Java 컴파일 통과. 실제 기기 실행은 미검증입니다.
- APK 릴리스는 아직 게시하지 않았습니다. 기존 설치본의 서명 키를 확보한 뒤 업데이트용 APK를 준비합니다.

## 업데이트

비공개 저장소에서 APK를 받으려면 접근 권한이 있는 GitHub 계정으로 로그인해야 합니다. 같은 패키지·기존 서명을 유지하고 versionCode를 높인 APK는 기존 앱 위에 설치해 업데이트할 수 있습니다.

현재 앱 내 업데이트 기능은 공개 GitHub 배포 경로를 사용합니다. 완전 비공개 저장소의 자동 다운로드에는 별도의 인증 지원이 필요하며 아직 구현하지 않았습니다. GitHub 웹 로그인 상태는 Android 앱의 다운로드에 공유되지 않습니다.

서명 키·비밀번호·접근 토큰은 이 저장소나 APK에 포함하지 않습니다.
