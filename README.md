# M4 Launcher

개인 시험용 Android 런처 배포 공간입니다. 앱 소스와 서명 키는 포함하지 않습니다.

## 다운로드

[1.4.0-rc12-personal APK 받기](https://github.com/DANDAN-TT/m4-launcher/releases/tag/v1.4.0-rc12-personal)

앱 자리 교환, 시작 지연·인터넷 대기·순차 실행, 조합별 DPI, 최근 앱 버튼, 넓은 하단 바 조합 바로가기를 추가했습니다.

## 처음 설치

앱 식별자는 `com.totb.m4launcher`이고 새 개인 서명 키를 사용합니다. 기존 앱과 별도로 설치됩니다. **기존 앱에서 설정 백업 → 새 APK 설치 → 설정 복원 → 기본 런처·연결 권한 설정** 순서로 진행하세요. 기존 앱은 복원 확인 후 필요에 따라 제거할 수 있습니다.

이후 개인 배포본끼리는 같은 키와 패키지를 유지하며 더 높은 버전으로 업데이트합니다.

## 업데이트

APK와 업데이트 정보는 공개되어 있어 GitHub 로그인 없이 받을 수 있습니다. 앱 소스와 개인 서명 키는 이 배포 저장소에 포함하지 않습니다.

이 개인 시험 배포는 preview 채널을 사용합니다. 앱의 **설정 → 관리·업데이트 → 업데이트 → 시험 버전 받기**를 켜세요. 같은 개인 서명과 패키지를 유지하는 후속 버전이 배포되면 이 채널에서 업데이트할 수 있습니다.
