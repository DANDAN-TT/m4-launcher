# M4 Launcher

Android 런처 시험 배포 공간입니다. 앱 소스와 서명 키는 포함하지 않습니다.

## 다운로드

[1.4.0-rc129 APK 받기](https://github.com/DANDAN-TT/m4-launcher/releases/tag/v1.4.0-rc129)

설정의 기본 분류 9개는 유지하고 세부 화면을 24개에서 15개로 통합했습니다. 관련 옵션을 한 화면에 모으고 메뉴가 하나인 분류는 바로 엽니다. 상태 정보는 메뉴가 좌우에 있을 때 사이드바 아래에, 하단 메뉴일 때 하단에 표시합니다. 시계·날짜·지역명과 날씨·기온·CPU 온도·사용률을 정리했으며 표시 항목과 CPU 표시 방식·온도 단위는 설정 → 조작 → 상태 정보에서 관리합니다.

좌우 버튼 바는 144dp의 같은 크기 두 열로 기능별로 정렬하며, ‘앱’은 큰 버블로 열립니다. 항상 즐겨찾기부터 표시하고 좌우 스와이프로 전체 앱 페이지를 넘깁니다. 상단 탭과 하단 화살표·페이지 표시를 제공하며 길게 누르면 앱 옵션을 엽니다. 별도의 즐겨찾기·최근 앱 버블도 제공합니다.

기본 홈 앱이 아니면 실행 시 설정을 안내합니다. 루트 연결에서는 내비 광고 닫기를 켤 때 M4 Launcher 접근성을 자동으로 준비하며 다른 앱의 접근성을 보존합니다. 개발자 옵션은 설정 열기 버튼 하나로 정리했습니다.

홈 화면에는 선택형 대시보드를 추가했습니다. 설정에서 시계·속도·미디어 중심 배치를 선택하고 이전 배치로 되돌릴 수 있습니다. 앱 표시 크기는 예시와 네 가지 빠른 선택을 제공하며, 기본 선택은 공통 크기를 따릅니다. 즐겨찾기·최근 앱 팝업은 제목·닫기 버튼과 큰 아이콘을 사용하고 높이가 부족하면 스크롤로 모든 행에 접근합니다. 설정의 공통 터치 높이는 최소64dp이며 주간에도 작업 영역 사이 틈과 하단 상태줄은 어둡게 유지합니다.

## 설치와 업데이트

기존 M4 Launcher 배포본은 같은 패키지 `com.totb.m4launcher`와 서명을 유지하므로 APK를 설치해 업데이트할 수 있습니다. 저장한 설정과 앱 선택을 유지합니다.

이전 `com.totb.drivedeck` 앱을 사용한다면 별도 앱으로 설치됩니다. **기존 앱에서 설정 백업 → M4 Launcher 설치 → 설정 복원 → 기본 런처·연결 권한 설정** 순서로 진행하세요.

APK와 업데이트 정보는 GitHub 로그인 없이 받을 수 있습니다. 앱의 **설정 → 관리 → 버전 업데이트 → 시험 버전 받기**를 켠 뒤 같은 화면에서 **새 버전 확인**을 누르세요.

## 엠스틱 관리

**설정 → 기기 → 기기 연결 → 엠스틱 관리(루트)**에서 Mgears 업데이터 비활성화, 부팅 안내창 숨김, 흰색 시스템 버튼 숨김과 CPU 최대 클럭 약 90%·80%·70%·60% 제한을 설정합니다. 변경 확인과 적용 상태 표시, 이전 설정 복구를 제공합니다.

루트 권한이 필요하며 부팅 안내·CPU 유지에는 Magisk가 필요합니다. 검사한 Mstick4 펌웨어 1.9.4·Mstick 앱 2.39.9에서 지원합니다. CPU는 최대 클럭을 제한하며 기기의 과열 보호를 유지합니다. 시스템 버튼은 M4 화면에서만 숨기며 외부 설정·파일 선택창으로 나가거나 런처를 종료하면 다시 표시합니다. 숨기기 옵션을 끄면 이전 제조사 설정을 복원합니다. 업데이터·부팅 안내·CPU의 지속 설정은 앱 삭제만으로 복구되지 않으므로 해제하거나 전체 복구를 먼저 사용하세요.

## 날씨와 접근성

현재 위치 날씨는 사이드바 상태 정보와 설정에 조회한 시·구 등 대략적인 지역명을 표시합니다. 위치 수신 대기·지역 확인 중·지역명 확인 불가를 구분하며, 수동 지역 선택도 지원합니다. 대략적인 위치 권한만 사용하고 약 10km 단위 지역을 Android 지역명 서비스와 Open-Meteo로 보냅니다. 상세 주소·정확한 좌표·이동 기록은 저장하지 않습니다. 기기 센서 온도와 예보 기온은 구분해 표시합니다.

내비 광고 닫기는 접근성으로 지원 내비의 닫기 버튼을 누릅니다. 광고 다운로드 차단 기능은 아닙니다. 루트 자동 준비가 실패하면 Android 접근성 설정으로 안내합니다. 앱별 등록은 토글 하나로 관리하며, 끄고 해제를 확인한 뒤 다시 켜면 새 버튼 등록을 시작합니다. 별도의 다시 등록 버튼은 제거했습니다. 전체 광고 자동 닫기를 끌 때는 등록을 보존합니다.

## rc93 이후 변경

홈 시계의 끝 숫자 잘림, 세로 스크롤 중 슬라이더 오입력과 공통 앱 크기 트랙의 짧은 탭 점프를 고쳤습니다. 앱 표시 크기는 ‘작게·맞춤’을 통합하고 낮은 창의 불필요한 스크롤을 줄였으며 큰 글자에서는 균등 격자로 선택합니다. 낮은 버튼 바의 더보기, 업데이트 상태 표시, 하단 정렬과 숨긴 구역의 키 포커스도 개선했습니다. 루트 작업 결과는 해당 작업의 확인된 상태로 표시합니다.

rc129는 144dp의 동일한 두 열 사이드바를 유지하면서 홈 카드 여백·좁은 음악 카드·설정 분류명을 다듬었습니다. 큰 앱 버블의 빈 즐겨찾기 안내와 전체 앱 버튼, 홈 배경 선택·64dp 앱 필터를 개선했습니다. 접근성 실제 연결 상태를 광고 토글에 반영하며, 60초 등록 중 정적인 팝업의 후보를 갱신합니다. 관찰된 티맵 광고 구조만 엄격하게 구분하고 카카오내비는 등록한 닫기를 사용합니다.

런처 안의 Android 권한 화면이 가려진 터치로 차단되는 경우, 기존 화면을 전체 화면으로 옮깁니다. 첫 터치는 화면 전환에 사용하며 이후 권한은 사용자가 직접 선택합니다. 터치 보안 플래그 제거·자동 권한 승인은 하지 않습니다.

## 검증과 알려진 문제

Java17·SDK34 release/debug 빌드, JVM 검사 각각907개, 린트 오류0·경고154, 한영1151쌍, 개인 서명·정렬·업데이트 경로를 확인했습니다. 최종 APK는 USB 엠스틱4에 설치해 확인한 파일입니다.

카카오내비 쿠폰 팝업과 티맵 광고 팝업은 실제 재실행 뒤 자동으로 닫히는 것을 확인했습니다. 네이버지도는 검사 중 광고가 나타나지 않아 자동 닫기를 확인하지 못했습니다. 모든 광고 변형의 성공을 보장하지 않습니다. 강제 종료 등으로 Android에서 접근성이 꺼지면 광고 닫기 설정에서 다시 켜야 하며 꺼진 상태를 표시합니다.

최종 설치본의 집중 네이티브 검사5개 중3개를 통과했고, 내비 확대 시 다른 구역의 잔상에 관한 기존2개는 실패했습니다. **이 잔상과 외부 화면 복귀 시 구역 앱 재로딩은 미해결입니다.** 실패 검사를 제외하거나6000ms 한도를 늘리지 않았습니다. 이전 rc128의 전체112개 검사는109통과·기존 잔상2실패·측정 드라이버1실패였으며, 드라이버 보정 뒤 해당1개만 별도 통과했습니다. 이를 rc129 전체 검사 통과로 합산하지 않습니다.

Android 권한 화면의 ‘허용 안 함’이 원 요청 화면에 전달되는 것과 권한 목록·상세 화면 이동을 확인했습니다. 타사 내비 권한, CPU60·HOME·무선 디버깅 꺼짐과 저장 설정을 유지했습니다. 좁은 구역에서 타사 앱 버튼이 잘리면 설정 → 화면 → 앱 크기의 ‘맞춤’ 또는 작은 값을 선택하세요.

앞서 관찰된 시스템 그래픽 리소스·입력기 오류의 근본 원인과 장시간 안정성은 계속 조사합니다. 실제 차량 부팅·주행, DRM, 위치 환경 전체의 날씨 성공과 발열 절감은 이번 배포에서 검증하지 않았습니다. 전체 기능 목록의 계획·부분 구현 항목도 완료로 간주하지 않습니다.
