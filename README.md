# M4 Launcher

Android 런처 시험 배포 공간입니다. 앱 소스와 서명 키는 포함하지 않습니다.

## 다운로드

[1.4.0-rc38 APK 받기](https://github.com/DANDAN-TT/m4-launcher/releases/tag/v1.4.0-rc38)

설정의 기본 분류 9개는 유지하고 세부 화면을 24개에서 15개로 통합했습니다. 관련 옵션을 한 화면에 모으고 메뉴가 하나인 분류는 바로 엽니다. 하단 상태줄은 날씨·기기 정보·연결 배지·날짜·시계로 정렬한 얇은 패널로 바꿨습니다. 표시 항목과 CPU 표시 방식·온도 단위는 설정 → 조작 → 하단 상태줄에서 관리합니다.

버튼 바는 세로 가운데에 정렬하며, 즐겨찾기·최근 앱·앱은 버튼 위치에 맞춘 버블로 열립니다.

기본 홈 앱이 아니면 실행 시 설정을 안내합니다. 루트 연결에서는 내비 광고 닫기를 켤 때 M4 Launcher 접근성을 자동으로 준비하며 다른 앱의 접근성을 보존합니다. 개발자 옵션은 설정 열기 버튼 하나로 정리했습니다.

## 설치와 업데이트

기존 M4 Launcher 배포본은 같은 패키지 `com.totb.m4launcher`와 서명을 유지하므로 APK를 설치해 업데이트할 수 있습니다. 저장한 설정과 앱 선택을 유지합니다.

이전 `com.totb.drivedeck` 앱을 사용한다면 별도 앱으로 설치됩니다. **기존 앱에서 설정 백업 → M4 Launcher 설치 → 설정 복원 → 기본 런처·연결 권한 설정** 순서로 진행하세요.

APK와 업데이트 정보는 GitHub 로그인 없이 받을 수 있습니다. 앱의 **설정 → 관리 → 버전 업데이트 → 시험 버전 받기**를 켠 뒤 같은 화면에서 **새 버전 확인**을 누르세요.

## 엠스틱 관리

**설정 → 기기 → 기기 연결 → 엠스틱 관리(루트)**에서 Mgears 업데이터 비활성화, 부팅 안내창 숨김, 흰색 시스템 버튼 숨김과 CPU 최대 클럭 약 90%·80% 제한을 설정합니다. 변경 확인과 적용 상태 표시, 이전 설정 복구를 제공합니다.

루트 권한이 필요하며 부팅 안내·CPU 유지에는 Magisk가 필요합니다. 검사한 Mstick4 펌웨어 1.9.4·Mstick 앱 2.39.9에서 지원합니다. CPU는 최대 클럭을 제한하며 기기의 과열 보호를 유지합니다. 시스템 버튼은 M4 화면에서만 숨기며 외부 설정·파일 선택창으로 나가거나 런처를 종료하면 다시 표시합니다. 숨기기 옵션을 끄면 이전 제조사 설정을 복원합니다. 업데이터·부팅 안내·CPU의 지속 설정은 앱 삭제만으로 복구되지 않으므로 해제하거나 전체 복구를 먼저 사용하세요.

## 날씨와 접근성

현재 위치 날씨는 하단 상태줄과 설정에 조회한 시·구 등 대략적인 지역명을 표시합니다. 위치 수신 대기·지역 확인 중·지역명 확인 불가를 구분하며, 수동 지역 선택도 지원합니다. 대략적인 위치 권한만 사용하고 약 10km 단위 지역을 Android 지역명 서비스와 Open-Meteo로 보냅니다. 상세 주소·정확한 좌표·이동 기록은 저장하지 않습니다. 기기 센서 온도와 예보 기온은 구분해 표시합니다.

내비 광고 닫기는 접근성으로 지원 내비의 닫기 버튼을 누릅니다. 광고 다운로드 차단 기능은 아닙니다. 루트 자동 준비가 실패하면 Android 접근성 설정으로 안내합니다. 앱별 등록은 토글 하나로 관리하며, 끄고 해제를 확인한 뒤 다시 켜면 새 버튼 등록을 시작합니다. 별도의 다시 등록 버튼은 제거했습니다. 전체 광고 자동 닫기를 끌 때는 등록을 보존합니다.

## 검증

release/debug 빌드, JVM 단위 테스트 각각 808개(실패·오류·건너뜀 0개), 린트 오류 0개·경고 143개, 한·영 문자열 1074쌍, Android 테스트 APK 컴파일과 기존 서명 검증을 통과했습니다.

이번 배포는 실제 Android 13 USB 엠스틱4에서 등록 화면·등록 시작 안내와 전체 자동 닫기 토글의 확인·취소·해제·재활성화를 확인했습니다. 기존 제품 설정을 보존했고 OEM 접근성을 유지하면서 M4 접근성을 자동 준비했습니다. 상용 광고의 실제 버튼 재등록은 미검증입니다. 이전 rc37 배포에서는 개발자 설정·파일 선택창의 뒤로 버튼과 Mgears 설정의 홈 버튼으로 빠져나오는 동작을 확인했습니다. 최종 APK에서 외부 화면 진입·M4 복귀·강제 종료 시 버튼 복구·재실행 시 숨김·옵션 해제 시 이전 값 복원을 확인했습니다. 저장한 설정을 보존했으며 무선 디버깅 꺼짐 상태를 유지했습니다. 전체 계측 묶음은 실행하지 않았습니다. 이전 배포에서 하단 패널, 설정 9개 분류·15개 세부 화면, 버튼 간격·버블 위치·동일한 온도 표시·기본 홈 앱 안내·개발자 설정 열기·루트 접근성 자동 연결을 확인했습니다.

이전 rc36 배포에서 실제 USB 엠스틱4의 공개된 서울 테스트 지점 Android 지역명 응답을 단일 계측 검사로 확인했습니다. 장치의 실제 현재 위치는 실내에서 수신되지 않아 지역명·자동 예보의 전체 성공 흐름은 미검증입니다. 제품의 수신 대기 표시와 성남 수동 지역 복원을 확인했습니다. 사용자 기기의 전체 자동 계측 묶음, 실제 차량 부팅 안내창 생략 장면, 상용 내비 광고·DRM 재생·발열 감소량은 미검증입니다.
