# M4 Launcher — 개인 비공개 배포

DANDAN-TT 소유의 비공개 APK 배포 공간입니다.

## 준비 중인 버전

- 1.4.0-rc12-personal (versionCode 90), 패키지 com.totb.drivedeck.
- 앱 자리 교환, 시작 지연·인터넷 대기·순차 실행, 조합별 DPI, 최근 앱 버튼, 넓은 하단 바 조합 바로가기를 추가했습니다.
- 개발 빌드의 단위 테스트 749개, 린트 오류 0개·경고 141개, 기기 테스트 Java 컴파일이 통과했습니다. 실제 기기 실행은 미검증입니다.
- 사용자 요청으로 새 개인용 서명 키를 생성했습니다. APK 릴리스는 아직 게시하지 않았습니다.

## 첫 설치와 이후 업데이트

새 개인 서명은 기존 공개 배포본과 다릅니다. 기존 앱 위에 바로 설치할 수 없으므로 먼저 앱 설정을 백업하고, 기존 앱을 제거한 뒤 개인 APK를 설치해 설정을 복원해야 합니다. 연결 권한은 다시 설정할 수 있습니다.

이 개인 APK 이후에는 같은 서명 키·패키지를 유지하고 versionCode를 높여 기존 앱 위에 업데이트합니다. 서명 키와 비밀번호는 로컬에만 보관합니다.

## 배포 공개 범위

현재 저장소는 비공개입니다. APK 다운로드에는 저장소 접근 권한이 있는 GitHub 계정 로그인이 필요합니다.

현재 앱 내 업데이트는 공개 GitHub 경로를 사용합니다. 처음만 수동 설치하고 이후 앱 안의 업데이트를 그대로 쓰려면 APK와 업데이트 정보가 공개되어야 합니다. 앱 소스나 서명 키를 공개할 필요는 없습니다. APK까지 완전 비공개로 유지하려면 별도의 인증 지원을 개발해야 합니다. GitHub 웹 로그인 상태는 Android 앱의 다운로드에 공유되지 않습니다.

공개 배포 전에는 사용자의 공개 범위 선택이 필요합니다. 접근 토큰이나 서명 비밀번호를 APK에 넣지 않습니다.
