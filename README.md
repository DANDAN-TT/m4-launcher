오브를 누르면 비서가 직접 마이크 입력을 받아 Android 인식기에 전달하고 발화 종료·취소·닫기 때 해제합니다. 말한 내용과 일치하는 길안내 명령은 앱과 목적지를 보여준 뒤 작은3·2·1 카운트다운으로 자동 검색합니다. 불명확한 명령과 화면 주소·설정 변경은 확인 조작을 유지합니다. 분명한 집·회사 명령은 장소를 표시한 뒤 카운트다운으로 진행합니다.

말하는 내용은 최대280dp의 작은 말풍선에 실시간으로 표시하며 새 문장이 들어오면 최신 마지막 줄을 따라갑니다. 전체 문장을 유지하고 새 인식이 없을 때는 사용자가 읽던 위치를 보존합니다. 비서 답변은 음성을 다 읽은 뒤 작은3·2·1 카운트다운을 보이고 자동으로 닫힙니다. 인식문장이 없으면 빈 창을 띄우지 않으며 확인·내비 선택창에는 답변 자동닫기를 적용하지 않습니다. 오브는 대기32dp 보라색, 누름·듣기44dp 청록색, 처리44dp 파란색으로 표시합니다. 저장한 사진·앱 배치·설정과 카드 없는 홈, 기존4×2 버튼·A·2×2 정보를 유지합니다.

설정의 기본 분류 9개는 유지하고 세부 화면을 24개에서 15개로 통합했습니다. 관련 옵션을 한 화면에 모으고 메뉴가 하나인 분류는 바로 엽니다. 상태 정보는 메뉴가 좌우에 있을 때 사이드바 아래에, 하단 메뉴일 때 하단에 표시합니다. 시계·날짜·지역명과 날씨·기온·CPU 온도·사용률을 정리했으며 표시 항목과 CPU 표시 방식·온도 단위는 설정 → 메뉴 → 정보 표시에서 관리합니다.

좌우 버튼 바는 같은 크기 두 열 네 줄로 기능별로 정렬하며, ‘앱’은 큰 버블로 열립니다. 즐겨찾기·최근 앱·모든 앱을 탭으로 고르고 각 목록을 위아래로 스크롤합니다. 머리에서 내비·앱·셋째 화면 대상을 바꾸며, 앱을 길게 눌러 옵션을 열었다가 닫으면 같은 대상·탭·위치로 돌아옵니다. 별도의 즐겨찾기·최근 앱 버블도 제공합니다.

기본 홈 앱이 아니면 실행 시 설정을 안내합니다. 루트 연결에서는 내비 광고 닫기를 켤 때 M4 Launcher 접근성을 자동으로 준비하며 다른 앱의 접근성을 보존합니다. 개발자 옵션은 설정 열기 버튼 하나로 정리했습니다.

홈 화면에는 선택형 대시보드를 추가했습니다. 설정에서 시계·속도·미디어 중심 배치를 선택하고 이전 배치로 되돌릴 수 있습니다. 앱 표시 크기는 예시와 네 가지 빠른 선택을 제공하며, 기본 선택은 공통 크기를 따릅니다. 즐겨찾기·최근 앱 팝업은 제목·닫기 버튼과 큰 아이콘을 사용하고 높이가 부족하면 스크롤로 모든 행에 접근합니다. 좁은 측면 조작 바는 전체가 보이도록 함께 축소합니다. 작은 설정 조작부의 모든 터치 크기를 이번에 확대했다는 뜻은 아닙니다. 주간에도 작업 영역 사이 틈과 하단 상태줄은 어둡게 유지합니다.

## 설치와 업데이트

기존 M4 Launcher 배포본은 같은 패키지 `com.totb.m4launcher`와 서명을 유지하므로 APK를 설치해 업데이트할 수 있습니다. 저장한 설정과 앱 선택을 유지합니다.

이전 `com.totb.drivedeck` 앱을 사용한다면 별도 앱으로 설치됩니다. **기존 앱에서 설정 백업 → M4 Launcher 설치 → 설정 복원 → 기본 런처·연결 권한 설정** 순서로 진행하세요.

APK와 업데이트 정보는 GitHub 로그인 없이 받을 수 있습니다. 앱의 **설정 → 관리 → 버전 업데이트 → 시험 버전 받기**를 켠 뒤 같은 화면에서 **새 버전 확인**을 누르세요.

## 엠스틱 관리

**설정 → 기기 → 기기 연결 → 엠스틱 관리(루트)**에서 Mgears 업데이터 비활성화, 부팅 안내창 숨김, 흰색 시스템 버튼 숨김과 CPU 최대 클럭 약 90%·80%·70%·60% 제한을 설정합니다. 변경 확인과 적용 상태 표시, 이전 설정 복구를 제공합니다.

루트 권한이 필요하며 부팅 안내·CPU 유지에는 Magisk가 필요합니다. 검사한 Mstick4 펌웨어 1.9.4·Mstick 앱 2.39.9에서 지원합니다. CPU는 최대 클럭을 제한하며 기기의 과열 보호를 유지합니다. 시스템 버튼은 M4 화면에서만 숨기며 외부 설정·파일 선택창으로 나가거나 런처를 종료하면 다시 표시합니다. 숨기기 옵션을 끄면 이전 제조사 설정을 복원합니다. 업데이터·부팅 안내·CPU의 지속 설정은 앱 삭제만으로 복구되지 않으므로 해제하거나 전체 복구를 먼저 사용하세요.

## 날씨와 접근성

현재 위치 날씨는 사이드바 상태 정보와 설정에 조회한 시·구 등 대략적인 지역명을 표시합니다. 위치 수신 대기·지역 확인 중·지역명 확인 불가를 구분하며, 수동 지역 선택도 지원합니다. 대략적인 위치 권한만 사용하고 약 10km 단위 지역을 Android 지역명 서비스와 Open-Meteo로 보냅니다. 상세 주소·정확한 좌표·이동 기록은 저장하지 않습니다. 기기 센서 온도와 예보 기온은 구분해 표시합니다.

내비 광고 닫기는 접근성으로 지원 내비의 닫기 버튼을 누릅니다. 광고 다운로드 차단 기능은 아닙니다. 기기 전체 광고 차단은 **설정 → 내비 → 알림·팝업 → 광고 차단 (기기 전체)**에서 따로 켭니다. 루트 자동 준비가 실패하면 Android 접근성 설정으로 안내합니다. 카카오내비·티맵의 지원 팝업은 앱별 토글로 관리합니다. 끄기 확인 뒤에도 등록은 보관하며, 다시 켜면 자동 닫기를 활성화합니다. 추가 닫기 버튼 등록과 등록 해제는 선택 화면에서 관리합니다.

## rc279까지의 개선 이력

아래는 이전 rc279까지의 원문 이력입니다. 이 절의 과거 기기 확인·시험 수치는 이번 rc280의 새 검증 결과가 아닙니다.

- **음성 설정과 목소리:** 서버 연결·비서·목소리·직접 해보기 네 카드로 정리했어요. 기기 한국어 목소리를 자동 또는 직접 선택하고 말 속도70~130%와 샘플을 사용할 수 있어요. 말풍선에는 실제 듣기·응답 상태 표시를 더했어요.
- **선택형 서버 음성:** 기존 HTTPS 서버 주소·API 키와 별도 음성 모델·목소리로 답을 읽을 수 있어요. 기본은 기기 읽기이며 서버가 /audio/speech의 MP3 응답을 지원해야 해요. 빈 모델·목소리는 해당 서버 기본값을 사용해요. 읽을 문장은 설정한 서버로 전송되며 음성 파일은 저장하지 않아요.
- **음성 지연과 취소:** 서버 첫바이트2.5초·재생시작4.5초 기한이나 재생 전 오류에는 기기 음성으로 전환해요. 새 요청·설정 변경·화면 이탈·일시정지는 이전 음성을 취소해요. 오디오 포커스가 거절되면 글만 표시하고, 재생 도중 실패해도 문장을 처음부터 반복하지 않아요. 발화 정리에서 숫자·시간·단위·범위를 보존해요.
- **음성 키와 검색 소유권:** 저장된 키를 입력칸에 복호화하지 않으며 마스킹·보기/숨기기·캡처 차단·백업/로그 제외를 유지해요. 미리 검색한 결과를 확인할 때 다시 읽어 비교하고, 바뀌면 일반 선택 흐름으로 돌아가요. 취소한 요청의 늦은 응답·내비 조작을 차단해요.
- **네이버와 티맵:** 네이버는 정확히 하나로 확인한 목적지 좌표로 길안내를 요청하고 확인된 경로의 시작 버튼을 한 번만 눌러요. 좌표가 모호하거나 링크가 실패하면 알리고 중단해요. 티맵은 기존 규칙에 맞는 시작 광고의 대기·닫기 탐색을 보강했어요.
- **앱 선택 대상:** 같은 선택창에서 내비·앱·셋째 화면 대상을 바꿀 수 있어요. 모든 탭·검색이 선택한 대상을 따르며 옵션에서 돌아와도 대상·탭·스크롤이 남아요. 좁은 창은 두 줄 머리로 바뀌고 즐겨찾기 우선 진입을 유지해요.
