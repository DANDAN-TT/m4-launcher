# M4 Launcher

Android 런처 시험 배포 공간입니다. 앱 소스와 서명 키는 포함하지 않습니다.

## 다운로드

[1.4.0-rc158 APK 받기](https://github.com/DANDAN-TT/m4-launcher/releases/tag/v1.4.0-rc158)

설정의 기본 분류 9개는 유지하고 세부 화면을 24개에서 15개로 통합했습니다. 관련 옵션을 한 화면에 모으고 메뉴가 하나인 분류는 바로 엽니다. 상태 정보는 메뉴가 좌우에 있을 때 사이드바 아래에, 하단 메뉴일 때 하단에 표시합니다. 시계·날짜·지역명과 날씨·기온·CPU 온도·사용률을 정리했으며 표시 항목과 CPU 표시 방식·온도 단위는 설정 → 메뉴 → 정보 표시에서 관리합니다.

좌우 버튼 바는 같은 크기 두 열 네 줄로 기능별로 정렬하며, ‘앱’은 큰 버블로 열립니다. 항상 즐겨찾기부터 표시하고 좌우 스와이프로 전체 앱 페이지를 넘깁니다. 상단 탭과 하단 화살표·페이지 표시를 제공하며 길게 누르면 앱 옵션을 엽니다. 별도의 즐겨찾기·최근 앱 버블도 제공합니다.

기본 홈 앱이 아니면 실행 시 설정을 안내합니다. 루트 연결에서는 내비 광고 닫기를 켤 때 M4 Launcher 접근성을 자동으로 준비하며 다른 앱의 접근성을 보존합니다. 개발자 옵션은 설정 열기 버튼 하나로 정리했습니다.

홈 화면에는 선택형 대시보드를 추가했습니다. 설정에서 시계·속도·미디어 중심 배치를 선택하고 이전 배치로 되돌릴 수 있습니다. 앱 표시 크기는 예시와 네 가지 빠른 선택을 제공하며, 기본 선택은 공통 크기를 따릅니다. 즐겨찾기·최근 앱 팝업은 제목·닫기 버튼과 큰 아이콘을 사용하고 높이가 부족하면 스크롤로 모든 행에 접근합니다. 설정의 공통 터치 높이는 최소64dp이며 주간에도 작업 영역 사이 틈과 하단 상태줄은 어둡게 유지합니다.

## 설치와 업데이트

기존 M4 Launcher 배포본은 같은 패키지 `com.totb.m4launcher`와 서명을 유지하므로 APK를 설치해 업데이트할 수 있습니다. 저장한 설정과 앱 선택을 유지합니다.

이전 `com.totb.drivedeck` 앱을 사용한다면 별도 앱으로 설치됩니다. **기존 앱에서 설정 백업 → M4 Launcher 설치 → 설정 복원 → 기본 런처·연결 권한 설정** 순서로 진행하세요.

APK와 업데이트 정보는 GitHub 로그인 없이 받을 수 있습니다. 앱의 **설정 → 관리 → 버전 업데이트 → 시험 버전 받기**를 켠 뒤 같은 화면에서 **새 버전 확인**을 누르세요.

## 엠스틱 관리

**설정 → 기기 → 기기 연결 → 엠스틱 관리(루트)**에서 Mgears 업데이터 비활성화, 부팅 안내창 숨김, 흰색 시스템 버튼 숨김과 CPU 최대 클럭 약 90%·80%·70%·60% 제한을 설정합니다. 변경 확인과 적용 상태 표시, 이전 설정 복구를 제공합니다.

루트 권한이 필요하며 부팅 안내·CPU 유지에는 Magisk가 필요합니다. 검사한 Mstick4 펌웨어 1.9.4·Mstick 앱 2.39.9에서 지원합니다. CPU는 최대 클럭을 제한하며 기기의 과열 보호를 유지합니다. 시스템 버튼은 M4 화면에서만 숨기며 외부 설정·파일 선택창으로 나가거나 런처를 종료하면 다시 표시합니다. 숨기기 옵션을 끄면 이전 제조사 설정을 복원합니다. 업데이터·부팅 안내·CPU의 지속 설정은 앱 삭제만으로 복구되지 않으므로 해제하거나 전체 복구를 먼저 사용하세요.

## 날씨와 접근성

현재 위치 날씨는 사이드바 상태 정보와 설정에 조회한 시·구 등 대략적인 지역명을 표시합니다. 위치 수신 대기·지역 확인 중·지역명 확인 불가를 구분하며, 수동 지역 선택도 지원합니다. 대략적인 위치 권한만 사용하고 약 10km 단위 지역을 Android 지역명 서비스와 Open-Meteo로 보냅니다. 상세 주소·정확한 좌표·이동 기록은 저장하지 않습니다. 기기 센서 온도와 예보 기온은 구분해 표시합니다.

내비 광고 닫기는 접근성으로 지원 내비의 닫기 버튼을 누릅니다. 광고 다운로드 차단 기능은 아닙니다. 루트 자동 준비가 실패하면 Android 접근성 설정으로 안내합니다. 카카오내비·티맵의 지원 팝업은 앱별 토글로 관리합니다. 끄기 확인 뒤에도 등록은 보관하며, 다시 켜면 자동 닫기를 활성화합니다. 추가 닫기 버튼 등록과 등록 해제는 선택 화면에서 관리합니다.

## 이번 변경

- 사이드바는 같은 크기 두 열 네 줄입니다. 홈/뒤로, 앱 목록/즐겨찾기, 내비/앱 화면, 분할/설정 순서로 배치합니다. 메뉴 버튼을 없애고 분할과 설정을 바로 엽니다. 최근 앱과 기존 보조 명령은 설정·길게 누르기에서 계속 사용할 수 있습니다.
- 시계·날짜·지역과 날씨·CPU 온도·사용률의 정렬과 간격을 정리했습니다. 날씨는 상태를 먼저 표시하고 긴 지역명은 두 줄로 표시합니다. 활성 화면의 위치 확인과 날씨 조회 주기를 분리해 같은 지역에서 불필요하게 다시 조회하지 않습니다.
- 홈의 빈 앱 영역에서 바로 앱을 고정하고, 첫 앱을 추가한 뒤에도 다음 앱을 쉽게 추가할 수 있습니다. 앱 목록의 선택 상태, 메뉴 아이콘, 옵션 설명과 고정된 닫기 버튼을 정리했습니다.
- 설정 → 분할에서 물리 키보드의 문자 입력을 보조 앱 구역에만 전달하는 옵션을 제공합니다. 소프트 키보드와 터치 입력은 양쪽 구역에서 사용할 수 있도록 분리했습니다.
- 설정 → 메뉴 → 정보 표시에서 기기 과열 알림과 비·눈 알림을 각각 관리합니다. 기본 켜짐이며 명시적으로 끈 설정은 보존합니다. 기존 온도·날씨 정보만 사용하며 새 위치 조회·타이머를 추가하지 않습니다. 첫 날씨 수신·지역 변경·복귀 시에는 조용히 기준을 잡고, 미리보기로 알림 모양을 확인할 수 있습니다.
- 앱 확대 시 가림막이 0×0 크기로 표시되지 않던 문제를 보완했습니다. 가림막을 미리 측정해 표시합니다. 다만 짧은 검정 잔상이 완전히 해결된 것은 아닙니다.
- 개인 패키지·서명, 기존 저장 설정과 DPI 명시적 적용 방식을 유지합니다. 음성 AI·모델 다운로드·주행 기록은 후속 작업이며 이번 APK에는 포함하지 않습니다.

## 검증 범위

- 소유 USB 엠스틱4에 설치한 것과 동일한 APK입니다. 최종 알림 토글·저장·미리보기·설정 복귀 10개 동작은 관찰 3640~4141ms로 기존 6000ms 한도 안이었고, 원래 사용자 설정과 두 열 버튼 영역을 보존했습니다.
- Java17·SDK34 Debug/Release 빌드와 JVM 검사 각각966개 통과, 린트 오류0·경고154, 한영1180쌍을 확인했습니다. Android 회귀 검사는 컴파일만 확인했으며 이번 배포의 전체 instrumentation 실행으로 주장하지 않습니다.
- 실제 Gboard로 양쪽 앱의 문자 입력을 확인했습니다. 실제 USB/Bluetooth 물리 키보드는 연결되지 않아 해당 장치의 입력 검증은 남아 있습니다.
- CPU60·무선 디버깅 꺼짐·기본 HOME·시스템 프로세스·접근성 보호 상태를 유지했습니다. 최신 설치 검사 중 새 런처 크래시나 멈춤은 관찰하지 않았습니다.

## 알려진 문제

- 티맵 확대 영상에서 가림막 뒤 오른쪽 검정이 8프레임(첫~끝142ms) 남았습니다. 기존 잔상 회귀 검사2건과 과거 6000ms 초과 응답 실패는 해결·전체 통과로 처리하지 않았습니다.
- 과거 종료 중인 카카오내비에서 네이티브 오류(SIGSEGV)3건을 관찰했습니다. 원인은 미확정입니다. 외부 화면 복귀 시 구역 앱 재로딩도 남아 있습니다.
- 카카오·티맵의 관찰한 광고 변형만 지원을 확인했습니다. 네이버지도 실제 광고와 모든 광고 변형의 성공을 보장하지 않습니다.
- 실제 주행, 소음 속 음성 인식, DRM 재생과 장시간 발열 절감은 이번 검증 범위가 아닙니다. 84개 기능 목록의 계획·부분 구현 항목은 완료 기능이 아닙니다.

## 업데이트

설정 → 관리 → 버전 업데이트 → ‘시험 버전 받기’를 켜고 ‘새 버전 확인’을 누르세요. 기존 개인 배포본은 삭제하지 않고 업데이트합니다.
