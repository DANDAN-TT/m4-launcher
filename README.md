# M4 Launcher

Android 런처 시험 배포 공간입니다. 앱 소스와 서명 키는 포함하지 않습니다.

## 다운로드

[1.4.0-rc247 APK 받기](https://github.com/DANDAN-TT/m4-launcher/releases/tag/v1.4.0-rc247)

오브를 누르면 비서가 직접 마이크 입력을 받아 Android 인식기에 전달하고 발화 종료·취소·닫기 때 해제합니다. 말한 내용과 일치하는 길안내 명령은 앱과 목적지를 보여준 뒤 작은3·2·1 카운트다운으로 자동 검색합니다. 불명확한 명령과 집/회사·화면 주소·설정 변경은 확인 조작을 유지합니다.

말하는 내용은 최대280dp의 작은 말풍선에 실시간으로 표시하며 새 문장이 들어오면 최신 마지막 줄을 따라갑니다. 전체 문장을 유지하고 새 인식이 없을 때는 사용자가 읽던 위치를 보존합니다. 비서 답변은 음성을 다 읽은 뒤 작은3·2·1 카운트다운을 보이고 자동으로 닫힙니다. 인식문장이 없으면 빈 창을 띄우지 않으며 확인·내비 선택창에는 답변 자동닫기를 적용하지 않습니다. 오브는 대기32dp 보라색, 누름·듣기44dp 청록색, 처리44dp 파란색으로 표시합니다. 저장한 사진·앱 배치·설정과 카드 없는 홈, 기존4×2 버튼·A·2×2 정보를 유지합니다.

설정의 기본 분류 9개는 유지하고 세부 화면을 24개에서 15개로 통합했습니다. 관련 옵션을 한 화면에 모으고 메뉴가 하나인 분류는 바로 엽니다. 상태 정보는 메뉴가 좌우에 있을 때 사이드바 아래에, 하단 메뉴일 때 하단에 표시합니다. 시계·날짜·지역명과 날씨·기온·CPU 온도·사용률을 정리했으며 표시 항목과 CPU 표시 방식·온도 단위는 설정 → 메뉴 → 정보 표시에서 관리합니다.

좌우 버튼 바는 같은 크기 두 열 네 줄로 기능별로 정렬하며, ‘앱’은 큰 버블로 열립니다. 항상 즐겨찾기부터 표시하고 좌우 스와이프로 전체 앱 페이지를 넘깁니다. 상단 탭과 하단 화살표·페이지 표시를 제공하며 길게 누르면 앱 옵션을 엽니다. 별도의 즐겨찾기·최근 앱 버블도 제공합니다.

기본 홈 앱이 아니면 실행 시 설정을 안내합니다. 루트 연결에서는 내비 광고 닫기를 켤 때 M4 Launcher 접근성을 자동으로 준비하며 다른 앱의 접근성을 보존합니다. 개발자 옵션은 설정 열기 버튼 하나로 정리했습니다.

홈 화면에는 선택형 대시보드를 추가했습니다. 설정에서 시계·속도·미디어 중심 배치를 선택하고 이전 배치로 되돌릴 수 있습니다. 앱 표시 크기는 예시와 네 가지 빠른 선택을 제공하며, 기본 선택은 공통 크기를 따릅니다. 즐겨찾기·최근 앱 팝업은 제목·닫기 버튼과 큰 아이콘을 사용하고 높이가 부족하면 스크롤로 모든 행에 접근합니다. 좁은 측면 조작 바는 전체가 보이도록 함께 축소합니다. 작은 설정 조작부의 모든 터치 크기를 이번에 확대했다는 뜻은 아닙니다. 주간에도 작업 영역 사이 틈과 하단 상태줄은 어둡게 유지합니다.

## 설치와 업데이트

기존 M4 Launcher 배포본은 같은 패키지 `com.totb.m4launcher`와 서명을 유지하므로 APK를 설치해 업데이트할 수 있습니다. 저장한 설정과 앱 선택을 유지합니다.

이전 `com.totb.drivedeck` 앱을 사용한다면 별도 앱으로 설치됩니다. **기존 앱에서 설정 백업 → M4 Launcher 설치 → 설정 복원 → 기본 런처·연결 권한 설정** 순서로 진행하세요.

APK와 업데이트 정보는 GitHub 로그인 없이 받을 수 있습니다. 앱의 **설정 → 관리 → 버전 업데이트 → 시험 버전 받기**를 켠 뒤 같은 화면에서 **새 버전 확인**을 누르세요.

## 엠스틱 관리

**설정 → 기기 → 기기 연결 → 엠스틱 관리(루트)**에서 Mgears 업데이터 비활성화, 부팅 안내창 숨김, 흰색 시스템 버튼 숨김과 CPU 최대 클럭 약 90%·80%·70%·60% 제한을 설정합니다. 변경 확인과 적용 상태 표시, 이전 설정 복구를 제공합니다.

루트 권한이 필요하며 부팅 안내·CPU 유지에는 Magisk가 필요합니다. 검사한 Mstick4 펌웨어 1.9.4·Mstick 앱 2.39.9에서 지원합니다. CPU는 최대 클럭을 제한하며 기기의 과열 보호를 유지합니다. 시스템 버튼은 M4 화면에서만 숨기며 외부 설정·파일 선택창으로 나가거나 런처를 종료하면 다시 표시합니다. 숨기기 옵션을 끄면 이전 제조사 설정을 복원합니다. 업데이터·부팅 안내·CPU의 지속 설정은 앱 삭제만으로 복구되지 않으므로 해제하거나 전체 복구를 먼저 사용하세요.

## 날씨와 접근성

현재 위치 날씨는 사이드바 상태 정보와 설정에 조회한 시·구 등 대략적인 지역명을 표시합니다. 위치 수신 대기·지역 확인 중·지역명 확인 불가를 구분하며, 수동 지역 선택도 지원합니다. 대략적인 위치 권한만 사용하고 약 10km 단위 지역을 Android 지역명 서비스와 Open-Meteo로 보냅니다. 상세 주소·정확한 좌표·이동 기록은 저장하지 않습니다. 기기 센서 온도와 예보 기온은 구분해 표시합니다.

내비 광고 닫기는 접근성으로 지원 내비의 닫기 버튼을 누릅니다. 광고 다운로드 차단 기능은 아닙니다. 루트 자동 준비가 실패하면 Android 접근성 설정으로 안내합니다. 카카오내비·티맵의 지원 팝업은 앱별 토글로 관리합니다. 끄기 확인 뒤에도 등록은 보관하며, 다시 켜면 자동 닫기를 활성화합니다. 추가 닫기 버튼 등록과 등록 해제는 선택 화면에서 관리합니다.

## 이번 변경

- 닫기 전환 중 들어온 필터·대상 구역 입력은 Main의 설정과 선택 상태에 반영하지 않습니다.
- 타일을 길게 누르던 중 뒤로가기로 목록을 닫으면, 남아 있던 긴 누르기 콜백이 앱 옵션을 다시 열지 않도록 합니다.
- 다시 연 목록의 정상 필터·대상 선택·길게 누르기와 기존 110ms 전환은 유지합니다. 목록 생성 시 대상 구역을 복구하는 기존 동작도 유지합니다.
- rc246의 닫힘 중 앱 선택 보호를 포함합니다. 이번 추가 보호는 Main에 반영되는 상태와 옵션 진입이며, 사라지는 목록 내부의 임시 표시를 고정하거나 자식 터치를 취소하는 변경은 아닙니다.

이전 개선도 포함합니다.

- 비서 버튼은 링과 세 막대의 A 오브입니다. 대기32dp 보라색에서 누름·듣기44dp 청록색, 처리44dp 파란색으로 바뀝니다. 회색 배경 없이 기존 누름 표시와 오류 테두리, 길게 눌러 음성 설정을 여는 동작을 유지합니다.
- 홈의 카드 상자를 제거하고 배경에 맞는 글자색과 내부 여백을 유지했습니다. 저장한 사진·위치·크기·비율과 음악의 기존 세 조작 버튼을 보존합니다.
- 기존 4행×2열 버튼·A·2행×2열 정보는 공간에 맞게 함께 줄어들며 버튼을 숨기거나 조작 바를 스크롤하지 않습니다. 축소된 실제 터치와 팝업 기준점을 맞추고 화면 크기가 바뀌면 열린 말풍선 위치도 다시 맞춥니다. 작은 화면에서는 실제 버튼과 글자도 줄어들며 모든 화면에서64dp를 보장하지 않습니다.
- v2 대화 지시문과 기본·싸가지의 고정 문구 묶음을 적용했습니다. 사실의 숫자·단위·장소 보존 검증과 실패 시 원문 사용, 대화 응답의 실행 금지를 유지합니다.
- 내비 결과 카드는 실제 이름과3초를 표시합니다. 선택된 카드의 카운트다운 중 최종 인식된 정확한 `응`·`네`·`그래`·`가자`·`출발`만 즉시 확정하며 취소를 먼저 처리합니다. 부분 인식·준비 전·기한 뒤 응답은 실행하지 않습니다. 말한 목적지와 일치하는 첫 길안내 명령은 표시 후3초 자동 검색합니다. 불명확한 명령은 확인을 유지합니다.
- 내비 단계별40회 또는8초 예산은 질문·선택 대기 중에만 멈춥니다. 요청 시작부터 전체30초에는 대기 시간도 포함하며 실제 단계 진행만 새 단계 예산을 받습니다.
- 종료한 내비의 늦은 선택·TTS·권한 응답과 대기 중 입력을 차단합니다. 권한 응답은 요청 당시 종류에 한 번만 처리하고, 입력의 고정500ms 신선도와 유효성을 UI·입력 큐 및DOWN 직전에 확인합니다.
- 안내 시작 탭 요청 뒤에도 확정된 다른 목적지·카드 변경·중복은 안내 표식보다 먼저 영구 중단합니다. 원래 화면이 돌아와도 재개하지 않고 자동 재탭·기한 연장은 하지 않습니다. 일반 지도·미리보기·클릭 수락은 안내 완료로 판정하지 않습니다.

기존 기능도 유지합니다.

- 앱 목록은 즐겨찾기가 먼저 열립니다. 최근 앱과 모든 앱을 같은 창의 탭에서 선택하고 좌우로 넘길 수 있습니다. 탭 글자가 줄거나 찌그러지던 너비 문제를 수정했습니다. 기존 즐겨찾기 바로가기와 길게 누르기 기능도 유지합니다.
- A 오브 버튼을 한 번 누르면 마이크 인식을 시작하고, 실제 인식문장이 도착하면 작은 말풍선에 실시간으로 보여줍니다. 최종 인식 문장이 도착하면 기존 해석기로 전달하고 답변·목적지 확인을 작은 창에 표시합니다. 길게 누르면 음성 설정으로 이동합니다.
- 명령 해석은 사용자가 지정한 OpenAI 호환 서버만 사용합니다. 서버 주소·API 키·모델 이름(선택)을 설정하며, 주소가 없으면 설정을 안내합니다. 연결 실패에는 1900ms 제한을 적용합니다. 이미 연결된 명령·사실 응답은 4초, 대화는 6초 제한입니다.
- 말한 목적지와 일치하는 길안내는 앱·목적지를 보여준 뒤3초 자동 검색합니다. 집/회사·화면 주소·설정 변경과 불명확한 명령은 확인 말풍선을 누른 후 실행합니다. 앱 화면·음악·볼륨·질문은 허용된 명령 범위에서 바로 실행합니다. 대화 응답을 행동 명령으로 실행하지 않습니다.
- 비서 말투 기본/싸가지를 제공합니다. 실제 데이터의 숫자·단위·장소를 보존하는 검증에 통과한 응답만 말투를 적용하고, 실패하면 원문을 사용합니다. 다른 국내 지역의 날씨 질문도 지원합니다.
- 내장 모델·모델 다운로드·llama.cpp/JNI/NDK 및 음성 처리 CPU 부스트 경로를 제거했습니다. API 키는 기기 암호화 별도 저장소에 보관하고 화면에서 마스킹하며 설정 백업에서 제외합니다. APK에는 기본 서버 주소나 키가 없습니다.
- 카카오내비 검색 결과의 정확한 주소 카드와 안내 시작 판정을 보완했습니다. 같은 내비에 음성 명령을 보낸 뒤 런처 뒤로가기가 다른 구역으로 전달되던 문제를 수정했습니다. 실행 전 접근성 검사와 승인된 복구 경로를 유지합니다.
- Netflix 프로필 화면 위에서 음성·설정·즐겨찾기·최근 앱의 표시와 터치 및 복귀를 확인했습니다. DRM 작품 재생 성공을 뜻하지 않습니다.
- 두 열 사이드바, 시계·날짜·지역 날씨·온도·사용률, 저장된 사용자 설정, 개인 패키지와 서명을 유지합니다. 취소한 햄버거·접기 기능은 추가하지 않았습니다.

## 알려진 문제

- 카카오 반복 검색에서 키보드가 남아 안내 실행에 실패하는 경우가 남아 있습니다. 이전 확인의 검색 수락부터11292ms·12406ms는6000ms 응답성 기준을 충족하지 못했습니다. 이전6721~7449ms의 기준 미달 기록도 유지합니다. 티맵은 이전 시험에서29.7초 지연을 관찰했습니다.
- 높은 누적 jank, 과거 포커스 ANR, 외부 화면 복귀와 확대 시 검정 잔상 및 카카오 종료 중 네이티브 오류는 전체 해결로 처리하지 않았습니다.
- 실제 사람 발화·안내 중 마이크·음성 긍정/취소/번호 선택·물리 키보드 타이핑·주행·DRM 작품 재생·장시간 발열 절감은 이번 직접 검증 범위가 아닙니다. 일반 연속대화·자동 다시듣기·RAM 대화 기억·직전 목적지 대명사 처리는 활성화하지 않았습니다. 모든 내비 광고 변형의 성공을 보장하지 않으며 84개 기능 목록의 계획·부분 항목은 완료 기능이 아닙니다.

- 실제 기기의 대상 변경·OS 권한 순서·서비스 종료·입력 브리지 내부 대기와 취소 반납·부팅 직후 버튼 누락 보고는 미검증입니다. 카드 부가문구의 변화도 보수적으로 중단될 수 있으며 정보가 부족한 전환은 대상 불변의 증명이 아닙니다.

## 업데이트

설정 → 관리 → 버전 업데이트 → 시험 버전 받기를 켜고 새 버전 확인을 누르세요. 기존 개인 배포본은 삭제하지 않고 설치합니다. A는 사용자 서버 설정 후 사용할 수 있습니다.

## 음성 개인정보와 업데이트 안내

- A는 사용자가 직접 설정하는 OpenAI 호환 서버가 필요하며, 공개본의 서버 주소·API 키·모델 이름 기본값은 모두 비어 있습니다. 말투 기본값은 기본입니다.
- 듣는 동안 마이크 소리는 선택된 Android 인식기에 전달되며 런처가 음성 파일을 저장하지 않습니다. 인식된 명령 문장과 명령 해석에 필요한 앱 목록은 설정한 서버로 전송됩니다. API 키는 기기 Keystore로 암호화하며 백업·로그에서 제외합니다. 사용자 서버 정보·기기 앱 목록을 담은 작업 문서는 공개 파일에 포함하지 않습니다.
- 이전 내장 모델을 사용했다면 업데이트 후 앱의 기존 모델 폴더를 자동 정리합니다. 이전 약1GB 다운로드의 저장 공간을 회수하며, 공개158에는 내장 모델이 없었으므로 그 버전에서 새로 삭제될 모델 파일은 없습니다.
