# M4 Launcher

Android 런처 시험 배포 공간입니다. 앱 소스와 서명 키는 포함하지 않습니다.

## 다운로드

[1.4.0-rc23 APK 받기](https://github.com/DANDAN-TT/m4-launcher/releases/tag/v1.4.0-rc23)

엠스틱4의 **설정 → 연결·기기 → 엠스틱 관리(루트)**에서 Mgears 업데이터 비활성화, 부팅 안내창 숨김, 흰색 시스템 버튼 숨김과 CPU 최대 클럭 약 90%·80% 제한을 설정할 수 있습니다. 확인창과 적용 상태 표시, 이전 설정 복구를 제공합니다. 내비 광고 닫기 접근성 권한을 주지 않고 돌아오면 토글도 꺼진 상태를 유지합니다. 이전 메뉴 개선과 성능 개선을 포함합니다.

## 설치와 업데이트

기존 M4 Launcher 배포본은 같은 패키지 `com.totb.m4launcher`와 서명을 유지하므로 APK를 설치해 업데이트할 수 있습니다. 저장한 설정과 앱 선택을 유지합니다.

이전 `com.totb.drivedeck` 앱을 사용한다면 별도 앱으로 설치됩니다. **기존 앱에서 설정 백업 → M4 Launcher 설치 → 설정 복원 → 기본 런처·연결 권한 설정** 순서로 진행하세요.

APK와 업데이트 정보는 GitHub 로그인 없이 받을 수 있습니다. 앱의 **설정 → 관리·업데이트 → 시험 버전 받기**를 켜고 업데이트를 확인하세요.

## 엠스틱 관리

루트 권한이 필요하며 부팅 안내·CPU 유지에는 Magisk가 필요합니다. 검사한 Mstick4 펌웨어 1.9.4·Mstick 앱 2.39.9에서 지원합니다. CPU는 사용률이 아닌 최대 클럭 제한이며 기기의 과열 보호를 유지합니다. 시스템 버튼 숨김은 제조사 설정을 사용합니다. 앱 삭제만으로 기기 설정이 복구되지 않으므로 해제하거나 전체 복구를 먼저 사용하세요.
